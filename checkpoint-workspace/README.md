# Checkpoint research workspace snapshot

This directory preserves the checkpoint scripts, notes and recorded experiment
artifacts that were developed in the parent workspace alongside this worktree.
The scripts currently assume that `scripts/` and `checkpoint-results/` are in
the parent workspace and that the CARLA source worktree is named
`deterministic-cpt`. They are not directly runnable from this snapshot without
recreating or adapting that layout. Paths in reports and notes describe the
original machine and may not exist elsewhere.

The AI walker transform-and-speed command changes in this snapshot were in
progress when work was paused. They have not been run or verified. Large-map
origin-shift tests and sensor integration remain incomplete. Some stored
reports document experiments outside the current scope, including impact
checkpoints; they are retained as historical evidence.
